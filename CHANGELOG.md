# Changelog

## v1.2.0 (2026-08-06) — «Упаковка к публикации»

Репозиторий приведён к тому же виду, что и `humanizer-ru`: мультиплатформенная
дистрибуция + честная мета-обвязка.

- **Мультиплатформенные манифесты:** Claude Code (`.claude-plugin/plugin.json`
  + `marketplace.json`), Codex (`.codex-plugin/plugin.json`), Cursor
  (`.cursor-plugin/plugin.json`), Gemini CLI (`gemini-extension.json`). Ставится
  как плагин в любом из четырёх агентов.
- **Мета-файлы:** `README.md` (RU) + `README.en.md` (EN), `LICENSE`,
  `CONTRIBUTING.md`, `SECURITY.md`, `PRIVACY_POLICY.md`, `SOURCES.md` (атрибуция
  anydoc и явная пометка про вендорские цифры).
- **CI:** `.github/workflows/ci.yml` — синтаксис-гейт обеих версий
  (`node --check`, `bash -n`) + smoke-тесты (`--help`, graceful missing-path).
  `plugin-scan.yml` — security-скан плагина. Issue-шаблоны и dependabot.
- **Ассеты:** иконки 128/256/512 и социальное превью.
- **Фикс категоризации в `convert.js`:** сбой запуска `npx`/anydoc (нет в PATH,
  код 126/127) больше не маскируется под `ПРОПУСК` («это скан, гоните OCR») —
  теперь честно уходит в `ОШИБКА`. Это выравнивает Node-версию с bash-версией:
  раньше при отсутствии `npx` они расходились (bash → ОШИБКА, js → ПРОПУСК),
  хотя документация обещала идентичное поведение.
- **Защита `convert.js` от циклов по симлинкам** при рекурсивном обходе папки.
- **Документация честности:** в `SKILL.md` явно оговорено, что контракт кодов
  возврата anydoc формально не задокументирован и трактуется консервативно; про
  плоский вывод `-o` и риск тёзок из разных подпапок добавлено предупреждение.

## v1.1 (2026-08-06)

- Добавлен `scripts/convert.js` — та же логика на Node.js, без bash. Решает
  адаптацию под Windows: `npx`/Node и так нужны для anydoc, поэтому
  кросс-платформенность досталась без нового рантайм-требования.
- На Windows обязателен `shell: true` при вызове `npx` (известная особенность
  Node — иначе `npx.cmd` не резолвится через PATH). Учтено в коде.
- Повторил на `convert.js` всю батарею тестов bash-версии (кириллица, коллизия
  имён, вложенная папка, missing path) — прошла.
- **Живой прогон на Windows не делал** — в песочнице нет Windows-окружения,
  только рассуждение о корректности кода. Спецсимволы `& ^ %` в путях на Windows
  не проверялись.
- `convert.sh` не удалён — работает как и раньше, обе версии держать в синхроне
  при правках.

## v1.0 (2026-08-06)

- Первая версия. Обёртка над `firecrawl/anydoc` (найден 06.08 в GitHub trending).
- `scripts/convert.sh`: пакетная конвертация файла / списка файлов / папки в
  Markdown, сводка OK/ПРОПУСК/ОШИБКА, вывод в `-o папку` или рядом с исходником.
- Найден и починен до релиза баг коллизии имён: файлы с одинаковым стемом и
  разным расширением (`отчёт.docx` + `отчёт.csv`) перезаписывали друг друга в
  `отчёт.md`. Исправлено — расширение исходника сохраняется в имени `.md`.
- Протестировано: `.csv` и `.docx` с кириллицей, папка с несколькими файлами,
  путь с пробелами, несуществующий путь в аргументах.
- Не тестировано: `.pptx`, `.xlsx`, `.pdf`, `.epub`, боевая пачка документов клиента.
