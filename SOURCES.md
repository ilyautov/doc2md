# Источники и атрибуция

## Движок конвертации

doc2md — тонкая обёртка над **[firecrawl/anydoc](https://github.com/firecrawl/anydoc)**
(MIT, написан на Rust). Вся собственно конвертация форматов в Markdown
выполняется anydoc; doc2md добавляет поверх пакетную обработку (файл / список /
папка), построчный статус и итоговую сводку `OK` / `ПРОПУСК` / `ОШИБКА`,
маршрутизацию сканов на OCR и русскую документацию.

- Репозиторий движка: https://github.com/firecrawl/anydoc
- npm-пакет: [`@firecrawl/anydoc`](https://www.npmjs.com/package/@firecrawl/anydoc)
- Лицензия движка: MIT

Апстрим публикует и свой минимальный skill (`npx skills add firecrawl/anydoc`) —
он конвертирует один файл за раз, без пакетной обработки и без сводки. doc2md
достраивает именно это.

## Бенчмарк

Цифры производительности и качества (первое место на 14 форматах, медиана
~4.4 мс/документ, «на два порядка быстрее конкурентов» — libreoffice /
unstructured / markitdown / pandoc / docling / mammoth на 100 документах) взяты
из README апстрима.

⚠️ **Это вендорские цифры авторов anydoc, независимо в этом репозитории не
перепроверялись.** Приводятся как заявление разработчиков движка, а не как
собственный результат doc2md.

## Что в этом репозитории — оригинальное

- Скрипты пакетной обёртки `skills/doc2md/scripts/convert.js` и `convert.sh`.
- Логика категоризации исхода и защита от коллизии имён (`<имя>.<расширение>.md`).
- Скилл `SKILL.md`, слэш-команда, документация, манифесты дистрибуции.

Всё оригинальное — под MIT (см. [LICENSE](LICENSE)).
